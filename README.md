# 🐍 Learning Python Language

A hands-on collection of beginner-to-intermediate Python programs, interactive mini-games, and practice scripts designed to master core Python syntax, data structures, and essential standard libraries.

![Python Version](https://img.shields.io/badge/python-3.x-blue.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)

---

## 📌 Overview

This repository serves as a personal learning space containing a variety of Python exercises and projects. The scripts transition from fundamental syntax exercises to logic-driven applications, demonstrating how core programming concepts solve real-world problems.

---

## 🚀 Key Concepts Covered

* **Core Data Structures:** Lists, Dictionaries, Tuples, Sets, and complex nested data manipulations.
* **Control Flow & Logic:** Conditional branching (`if/elif/else`), nested conditionals, `for` and `while` loops.
* **Functions & Scope:** Reusable code modules, parameters, return values, and variable scope management.
* **Built-in Standard Libraries:** Essential modules such as `random`, `math`, `time`, `os`, and `turtle`.

---

## 🎮 Featured Projects

The repository includes various projects, such as:

* **Card & Strategy Games:** Blackjack Game, Treasure Island
* **Cryptography & Security:** Caesar Cipher, Random Password Generator
* **Utility & Logic Apps:** Blind Auction, Pizza Delivery Calculator, and more!

*(More projects and scripts are added regularly as new concepts are covered.)*
